PROJECT SPECIFICATION
Pancreatic Cancer Segmentation — AttnUNet with Pretrained EfficientNet-B3 Backbone + 4-Layer Multi-Head Graph
Attention Network (GAT) + Explainable AI (Grad-CAM)
Dataset: Medical Segmentation Decathlon — Task 07 (Pancreas)
1. Project Overview
The goal of this project is to build an automated semantic segmentation pipeline for pancreatic CT scans that identifies three classes —
background, pancreas, and tumor — using an Attention U-Net framework coupled with an EfficientNet-B3 feature extractor and a 4-layer
Graph Attention Network (GAT) bottleneck. The model integrates Grad-CAM based explainability (XAI) to visualize and validate the spatial
regions and features driving tumor boundary delineation during clinical inference.
2. Dataset
 Source: Medical Segmentation Decathlon (MSD) — Task 07 (Pancreas).
 Classes: 3 — Background (Class 0), Pancreas (Class 1), Tumor (Class 2).
 Format: NIfTI (.nii.gz) volumetric CT scans preprocessed into 2D single-channel compressed .npz slice arrays.
 Data split: Training: 70%, Validation: 15%, Testing: 15%.
 Cross-validation: 5-fold cross-validation applied across the development pool (~68% Train / ~17% Validation per fold) with strict
case-level grouping to prevent slice-level data contamination.
3. Preprocessing Pipeline
Apply preprocessing steps in the following order:
1. Hounsfield Unit (HU) windowing (-100 to +250 HU) to isolate pancreatic soft tissue and eliminate bone/air artifacts.
2. Min-max normalization scaling voxel intensities to [0.0, 1.0].
3. Contrast Limited Adaptive Histogram Equalization (CLAHE) with clip limit 2.0 and tile grid (8, 8) to enhance hypodense lesion boundaries.
4. ROI-based localization and non-anatomical slice pruning.
5. Spatial resizing to uniform 128 × 128 resolution for GPU memory efficiency.
6. Dynamic class weight calculation with a 5.5× tumor penalty factor (Background: 0.0004, Pancreas: 0.0822, Tumor: 2.9174).
7. On-the-fly spatial augmentation and 8-pass Test-Time Augmentation (TTA) across 4 rotations (0°, 90°, 180°, 270°) and horizontal
reflections during evaluation.
4. Model Architecture — AttnUNet + EfficientNet-B3 + GAT
Encoder: Dual-pathway encoder combining a 4-stage standard CNN encoder (32 to 256 channels) and a pretrained EfficientNet-B3
backbone (384 output feature channels), feeding into a 4-layer Graph Attention Network (GAT) bottleneck, followed by an Attention U-Net
decoder with late feature fusion.

5. Training Configuration Summary
 Optimizer: AdamW | Learning rate: 1.8 × 10■■ (Cosine Annealing down to 1.0 × 10■■) | Weight decay: 2.5 × 10■■
 Loss function: Composite loss = 0.30 × Cross-Entropy + 0.45 × Dice + 0.25 × Focal + 0.50 × Focal Tversky Loss (α=0.3, β=0.7, γ=1.33)
 Batch size: 16 accelerated with PyTorch Automatic Mixed Precision (AMP) | Cross-validation: 5-fold cross-validation
 Training strategy: Batch-wise training with epoch-level checkpoint saving
6. Explainability & Validation Strategy
Use Grad-CAM targeting the deep bottleneck convolutional feature maps to inspect gradient flow for Class 2 (Tumor). The resulting
heatmaps are blended over raw CT slices to confirm that high activations correspond strictly to tumor margins and parenchymal boundaries
rather than background abdominal artifacts.

10. Additional Notes
The compound loss integrates an asymmetric Focal Tversky Loss (β=0.7) to penalize false negatives, maintaining high tumor recall (63.25%)
despite extreme foreground-background class imbalance (tumor pixels ≈ 0.1%).
