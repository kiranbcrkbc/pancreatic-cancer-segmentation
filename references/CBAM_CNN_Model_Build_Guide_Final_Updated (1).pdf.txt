1. Project Introduction
The aim is to build a deep learning system for pancreatic tumor segmentation from CT images. The system uses CNN for
feature learning, CBAM to focus on important features, and Grad-CAM as the explainability method. The final system is
therefore CNN + CBAM + Grad-CAM + Explainable AI.
2. Dataset & Target
 Dataset
Medical Decathlon — Pancreas (Task07)
Input
3D CT scans (.nii.gz)
Original labels
0 = Background · 1 = Pancreas · 2 = Tumor
Target
Binary tumor segmentation mask
3. Preprocessing Pipeline — Required Steps
Use all six preprocessing steps below before training the CNN + CBAM model.
01
ROI Patch Extraction
Extract fixed-size 3D patches centered on the
pancreas bounding box. This focuses the model on
the relevant region and reduces memory use.
02
CLAHE Enhancement
Use Contrast Limited Adaptive Histogram
Equalization to improve local contrast and make
pancreatic boundaries easier to see.
03
Targeted Zoom Augmentation
Apply scale-aware zoom around the pancreas
region using 0.7–1.4× magnification to simulate
anatomical size variation.
04
Elastic Deformation
Apply smooth spatial warping with random
displacement fields to mimic natural organ
deformation and improve generalization.
05
Multiscale Training
Train using 32³, 64³ and 128³ patches so the model
can learn both global context and fine local features.
06
Attention-Guided Augmentation
Use saliency maps from a teacher model to identify
important regions and concentrate augmentation in
those regions.

8. 5-Fold Cross-Validation
 Step
What to do
1
Split the data into 5 patient/volume-level folds.
2
Use 4 folds for training and 1 fold for validation.
3
Repeat until every fold has been used once for validation.
4
Train each fold for 10 epochs with batch size 8.
5
Save the metrics and checkpoint for every fold.
6
Report mean ± standard deviation across the 5 folds.
Important: Keep all slices/patches from the same patient or 3D volume in the same fold. This prevents data leakage.
9. Evaluation Metrics
 Metric
Simple meaning
Dice
Overlap between predicted tumor and true tumor.
IoU
Intersection over Union of prediction and ground truth.
Precision
How much of the predicted tumor is correct.
Recall
How much of the actual tumor was found.
F1 Score
Combines precision and recall.
Accuracy
Overall pixel-level correctness.
10. Grad-CAM + Explainable AI
Grad-CAM is the explainability method used with the model. Generate a Grad-CAM heatmap for predictions to show which
regions of the CT input contributed most to the model's decision. Save the original image, prediction mask, and Grad-CAM
visualization together for qualitative analysis.
