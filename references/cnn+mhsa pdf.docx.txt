1. Project Overview
The goal of this project is to build a 3D semantic segmentation pipeline for pancreatic CT scans that identifies three classes — background, pancreas, and tumor — using a Residual CNN encoder combined with a Multi-Head Self-Attention (MHSA) module. The model must also support Grad-CAM based explainability (XAI) to visualize and validate what regions the network is attending to when making predictions.
2. Dataset
Source: Medical Segmentation Decathlon (MSD) — Task 07 (Pancreas). the dataset is a strict requirement.
Classes: 3 — Background, Pancreas, Tumor.
Format: NIfTI (.nii.gz) volumetric CT scans with corresponding segmentation masks.
Data split:
Training: 70%
Validation: 15%
Testing: 15%
Cross-validation: 5-fold cross-validation is required on top of the above split (apply 5-fold CV within the training/validation pool, and report averaged metrics across folds).each fold should have min 20 ephocs.

4. Model Architecture — Residual CNN + MHSA
Encoder: Residual CNN (ResNet-style residual blocks) feeding into a Multi-Head Self-Attention module, followed by a decoder for pixel/voxel-wise segmentation output. Final numeric configuration below.

Explainability module: Grad-CAM must be integrated to visualize attention/activation regions driving the segmentation decision. Use Grad-CAM outputs both for qualitative validation (visual sanity-check against tumor location) and as an input signal to the attention-guided augmentation step in preprocessing.
Full architecture label as given by the project owner: "CNN + Multi-Head Self-Attention + Grad-CAM + Explainable AI."
